# Keyboard shortcuts

Full version: [wess.io/ambry/docs.html#shortcuts](https://wess.io/ambry/docs.html#shortcuts).

| Shortcut | Action |
|----------|--------|
| `⌘N` | New connection |
| `⌘↵` | Run the query buffer |
| Double-click | Edit the cell under the cursor |
| `Enter` | Commit the cell edit (while editing) |
| `Esc` | Cancel the cell edit |
| `⌘`-click | Toggle a row in/out of the selection |
| `⇧`-click | Select a contiguous range of rows |
| Click header | Sort by that column (click again to flip) |
| Drag header edge | Resize a column |
| `⌘H` | Hide Ambry |
| `⌘Q` | Quit |
