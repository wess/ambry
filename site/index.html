The database grid you can edit.

01

Three engines, one grid

The same editor, grid, and schema tools across every connection — with the differences that matter handled underneath.

PostgreSQL

Full introspection, foreign keys, SSL modes, and SSH tunnels. Column names resolve even for empty tables.

MySQL / MariaDB

Binary-protocol queries, index and key discovery, and the same connection options as Postgres.

SQLite

Open a file and go. Pragmatic introspection through PRAGMA, no server required.

02

Built for the work, not the demo

Everything you reach for in a day with a database — read, edit, query, inspect — in a tool that stays out of the way.

grid

An editable grid

Double-click to edit, multi-select rows, sort by any column, and drag column edges to resize. Edits collect as pending changes you review as SQL before you commit.

editor

A fast SQL editor

Syntax-highlighted SQL with multi-statement execution. Run with ⌘↵, read results in the same grid, and pull from query history.

schema

Structure at a glance

Columns, indexes, and foreign keys for any table, read straight from the live schema — not a cached guess.

connect

Connections that travel

SSL/TLS and SSH tunnels, groups and tags, safe mode, startup commands, and a live health check — saved as plain JSON you can read.

engines

One tool, every engine

Postgres, MySQL/MariaDB, and SQLite behind the same grid and editor. When a connection has more than one database, switch between them in place.

local

Local and yours

Connections, history, and settings live under ~/.ambry as files you can read. Nothing phones home. MIT-licensed, source in the open.

the workflow

See it, edit it, commit it — without leaving the grid.

Change a cell, insert a row, delete a few — every edit collects as a pending change and stays right there in the grid, marked in amber. When you’re ready, review the whole batch as the exact SQL it will run, then commit. You never issue a write you didn’t read first.

Install

macOS on Apple Silicon. Install with Homebrew, or download the disk image directly.

Homebrew

Recommended — Homebrew clears the quarantine flag, so it launches clean.

$ brew install --cask wess/packages/ambry

Direct download

Grab the disk image, mount it, and drag Ambry into Applications.
