An open-source database client that gets out of your way.

Ambry is a fast desktop client for PostgreSQL, MySQL/MariaDB, and SQLite. A CodeMirror SQL editor, an editable data grid, schema tools, ER diagrams, and charts — all built on Butter, React, and Mantine.

Features

Everything you need to read, write, and reshape your data.

One client, three engines, and the tooling to actually understand a schema.

🔌

Connection management

SSL/TLS, SSH tunneling, URL parsing, groups, tags, safe mode, startup commands, and health monitoring.

⌨️

SQL editor

CodeMirror 6 with autocomplete, 17 snippets, Vim mode, formatting, multi-tab, multi-statement, find/replace.

▦

Data grid

Inline editing, column resize/visibility, 18 filter operators, sorting, pagination, FK navigation, and change tracking with SQL preview.

🔍

Cell inspector

A detail sidebar for wide tables, with per-field copy so you never lose a value in a sea of columns.

◈

Schema tools

Structure viewer, data profiling (null %, distribution), and schema comparison with ALTER migration generation.

🕸️

ER diagram

An auto-generated SVG relationship diagram with draggable nodes and zoom for mapping your schema at a glance.

📊

Charts

Bar, line, and pie visualizations rendered straight from query results — zero dependencies.

🔄

Import / Export

CSV, JSON, and SQL with native file dialogs, clipboard paste, and drag-and-drop of .sql files.

🎲

Mock data

Type-aware generation for names, emails, dates, UUIDs, and more to fill tables for testing.

⏺️

Macros

Record, replay, manage, and export/import action sequences to automate the things you do every day.

⎈

Command palette

Cmd+P to quick-jump to tables, queries, and actions without lifting your hands off the keyboard.

🧩

Plugin system

Install and manage database drivers, export formats, and themes. Full light and dark themes across every component.

Tech stack

Native speed, a modern UI, and Bun's built-in drivers.

  • ✦Butter runtime — Bun plus a native webview, so the app ships small and starts fast.
  • ✦React 19 + Mantine 8 — a polished component UI with Tanstack Router and Tanstack Query underneath.
  • ✦CodeMirror 6 — the SQL editor, with sql-formatter and Vim keybindings built in.
  • ✦Bun built-in DB drivers — Postgres, SQLite, and MySQL talk to the database with no extra native deps.
  • ✦Lucide icons · MIT licensed — clean iconography across a codebase of 77 source files.

Get started

Install on macOS in one command.

The 1.0 release ships macOS (Apple Silicon / arm64) only. Homebrew strips quarantine so it launches clean.

install — homebrew 
# recommended: install the cask
brew install --cask wess/packages/ambry

# first time using this tap
brew tap wess/packages
brew install --cask ambry
develop from source 
# clone, install deps, and run in dev
git clone https://github.com/wess/ambry
cd ambry
bun install
bun run dev

Open the database, close the friction.

Ambry is MIT licensed and open source. Grab the latest release or build it yourself.
